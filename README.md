In this week's assignment, I created multiple classes User, Employee, and InventoryManager.

User was created as a base class with the virtual method accessLevel(). 

Employee was derived from User and overrides accessLevel and InventoryManager was derived from Employee and override accessLevel() as well. 

I also created header files for each class, then in my main function I created the InventoryManager object and called the virtual method to execute the InventoryManager version. 

This was done to cout all the different access levels in the class hierarchy (User, Employee, InventoryManager).
